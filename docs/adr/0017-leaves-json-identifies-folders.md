# 0017. フォルダの種類と ID は、各フォルダの `.leaves.json` で表す

- 状態: 承認
- 日付: 2026-09-28

## 背景
本棚フォルダを正本にすると（ADR 0016）、走査で見つけたフォルダが「ノートブック」か「ノート」か、また外部で名前変更・移動されたフォルダが以前のどれと同じかを判定する必要がある（FR-X-07: OCR 結果を引き継ぐ）。

## 決定
- 各フォルダに管理用ファイル `.leaves.json` を置き、`kind`（shelf / notebook / note）と `id` を書く
- `kind: note` の印があるフォルダだけをノートとし、印のないフォルダはノートブックとみなす（外部で作られたフォルダは、まずノートブックになる）
- ノートブック・ノートの直下に外部で置かれた画像は、1枚ずつ新しいノートとして取り込む（FR-X-06）
- ページの同一性は、ノートの `.leaves.json` に記録したファイル名、なければファイルサイズと更新日時の一致で判定する
- 同じ ID が2か所で見つかった場合（Finder での複製）は、後から見つかった方に新しい ID を振り直す

## 検討した選択肢
- **中身で判定する**（画像だけが入ったフォルダ＝ノート） — 空のフォルダや、画像とフォルダが混ざったフォルダで判定がぶれる。外部でフォルダを作って画像を入れた途中の状態でも結果が変わる
- **拡張子で判定する**（`名前.note` のようなフォルダ名） — Finder・「ファイル」アプリで名前が不自然になり、外部で作るときに付け忘れる
- **パスで同一性を判定する** — 名前変更・移動のたびに別のノートになり、OCR をやり直すことになる

## 結果
- 名前変更・移動・複製をしても ID で追いかけられ、OCR 結果が引き継がれる
- 利用者が `.leaves.json` を消すと、そのノートはノートブックに変わり、中の画像がノートとして取り込み直される（OCR はやり直しになる）。隠しファイルなので通常は触れられない前提とする
