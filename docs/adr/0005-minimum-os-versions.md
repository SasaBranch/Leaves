# 0005. 最低対応 OS を iOS 16.4 / Android 10 とする

- 状態: 承認
- 日付: 2026-09-28

## 背景
要件定義書では「iOS 16 以上、Android 10 以上を目標」とし、確定を基本設計に持ち越していた。

## 決定
iOS 16.4 以上、Android 10（API 29）以上とする。

## 検討した選択肢
- iOS 16.0 — 採用時点の最新 Expo SDK 57 が iOS 16.4 を最低要件としているため不可
- より新しい OS に絞る — 利点が特にない

## 結果
- Expo SDK 57 とスキャナ・OCR ライブラリの要件を満たす
- Expo SDK を上げると最低要件が上がることがある。その場合は新しい ADR で記録する
