# 0006. PDF に OCR テキストを透明テキストとして埋め込む

- 状態: 承認
- 日付: 2026-09-28

## 背景
PDF を画像だけで作ると、PC などで PDF 内の文字検索・コピーができない。

## 決定
OCR の行ごとの位置に、不可視の描画モード（PDF のテキストレンダリングモード 3）でテキストを重ねる。PDF 生成には pdf-lib ＋ @pdf-lib/fontkit を使い、同梱した Noto Sans JP を使用文字のみサブセット埋め込みする。そのために OCR 結果は全文（`ocr_text`）に加えて、行ごとの文字と位置（`ocr_lines`）も保存する。

## 検討した選択肢
- 画像だけの PDF — 実装は最も簡単だが、PDF 内検索ができない
- HTML から PDF を生成（expo-print）し、透明色の文字を重ねる — 透明色の文字が PDF のテキストとして残るかどうかが OS の印刷エンジンに依存し、確実でない

## 結果
- 書き出した PDF が検索・コピー可能になる
- 日本語フォント（数 MB）をアプリに同梱する
- pdf-lib は 2022 年以降更新されていない。PDF 仕様は安定しているため当面は問題ないと判断するが、生成時間・メモリを実装初期に検証する（基本設計書 R-2）
