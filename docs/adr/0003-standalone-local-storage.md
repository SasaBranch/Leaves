# 0003. Obsidian と連携せず、端末内の SQLite ＋画像ファイルで完結させる

- 状態: 承認
- 日付: 2026-09-28

## 背景
当初は既存の Obsidian Vault（iCloud 同期）に Markdown と画像を直接書き込む案だった。しかし Android からは iCloud 上のファイルに触れられず、iOS/Android 両対応と相性が悪い。

## 決定
Obsidian とは連携せず、アプリ単体で完結させる。データはメタデータを SQLite（expo-sqlite）、画像をアプリ専用領域のファイルに保存する。データの持ち出し口として Markdown / PDF エクスポートを用意する。同期は MVP では行わない。

## 検討した選択肢
- Obsidian Vault に直接保存 — PC の Obsidian と連携できるが、Android で iCloud に触れられない。フォルダ選択の権限を保持するネイティブモジュールの自作も必要
- Markdown ファイルとフォルダをそのままアプリ内に保存 — 外部互換がないなら、フォルダ移動・全文検索・並べ替えが DB より面倒になるだけ

## 結果
- フォルダ移動は親 ID の更新だけ、検索は SQLite の全文検索で済む
- データがアプリ内に閉じるため、エクスポート機能が持ち出しの唯一の手段になる
- 将来の同期に備え、全データに UUID と作成・更新日時を持たせる（要件 NFR-M-03）
